HTML

Guía rápida para el lenguaje de marcado HTML: estructura, meta, texto, enlaces, listas, multimedia, tablas, formularios, semántica y atributos

Estructura básica

La estructura básica de un documento HTML se compone de las siguientes partes:


                        <!-- Ejemplo: estructura mínima -->
                        <!DOCTYPE html>
                        <html lang="es">
                        <head>
                            <meta charset="UTF-8">
                            <meta name="viewport" content="width=device-width, initial-scale=1.0">
                            <title>Título</title>
                        </head>
                        <body>
                            <main>Contenido</main>
                        </body>
                        </html>
  • DOCTYPE primero.
  • meta charset lo más arriba posible.
  • meta viewport para responsive design.

Metaetiquetas

Básicos + SEO + redes sociales.


                        <meta charset="UTF-8">
                        <meta name="viewport" content="width=device-width, initial-scale=1.0">
                        <meta name="description" content="Descripción clara">
                        <meta name="robots" content="index, follow">
                        <link rel="canonical" href="https://ejemplo.com/pagina">
                        <meta property="og:title" content="Título">
                        <meta property="og:description" content="Descripción">
                        <meta property="og:image" content="https://ejemplo.com/img.jpg">

Encabezados y texto

Etiquetas para formatear texto.


                        <h1>Título principal</h1>
                        <h2>Subtítulo</h2>
                        <h3>Subsubtítulo</h3>
                        <h4>Encabezado 4</h4>
                        <h5>Encabezado 5</h5>
                        <h6>Encabezado 6</h6>
                        <p>Párrafo de texto.</p>
                        <strong>Texto importante</strong>
                        <em>Texto enfatizado</em>
                        <mark>Highlight</mark>
                        <br> <!-- Salto de línea -->
                        <hr> <!-- Línea horizontal -->
  • Usa <h1> una vez por página y respeta la jerarquía.

Enlaces y navegación

Cómo crear enlaces y enlaces accesibles.


                        <a href="https://ejemplo.com">Externo</a>
                        <a href="/ruta">Interno</a>
                        <a href="#seccion">Ancla</a>
                        <a href="https://ejemplo.com" target="_blank" rel="noopener noreferrer">
                        Nueva pestaña (seguro)
                        </a>
                        <nav aria-label="Principal">
                        <ul>
                        <li><a href="#inicio">Inicio</a></li>
                        </ul>
                        </nav>

Listas ordenadas, desordenadas y de definición.

                        <li>Primer elemento</li>

                        </dl>

Multimedia

Cómo insertar imágenes, audio y video.


                        <img src="imagen.jpg" alt="Descripción">
                        <audio controls>
                        <source src="audio.mp3" type="audio/mpeg">
                        </audio>
                        <video controls width="600">
                        <source src="video.mp4" type="video/mp4">
                        </video>

Formularios

Elementos básicos para crear formularios.


                        <form action="/submit" method="post">
                        <label for="nombre">Nombre:</label>
                        <input type="text" id="nombre" name="nombre">
                        <label for="email">Email:</label>
                        <input type="email" id="email" name="email">
                        <button type="submit">Enviar</button>
                        </form>
  • Siempre label + for conectado a un id.
  • Usa required, minlength, pattern cuando aplique.

Accesibilidad (A11y)

Buenas prácticas para mejorar la accesibilidad de tu sitio web.


                        <!-- Uso de ARIA -->
                        <nav aria-label="Principal">
                        <ul>
                        <li><a href="#inicio">Inicio</a></li>
                        </ul>
                        </nav>

                        <!-- Etiquetas semánticas -->
                        <header>Encabezado</header>
                        <main>Contenido principal</main>
                        <footer>Pie de página</footer>

                        <!-- Texto alternativo -->
                        <img src="imagen.jpg" alt="Descripción de la imagen">

                        <!-- Formularios accesibles -->
                        <label for="email">Email:</label>
                        <input type="email" id="email" name="email">

Mejores prácticas

  • HTML válido, indentación consistente.
  • Imágenes con alt descriptivo (o vacío si decorativa).
  • Links externos con rel="noopener noreferrer".
  • Performance: loading="lazy" en imágenes no críticas.
  • Testing: Validator, Lighthouse, WAVE / axe.
