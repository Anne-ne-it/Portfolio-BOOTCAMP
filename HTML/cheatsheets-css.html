Cheat Sheets

CSS

Guía rápida para el lenguaje de estilo CSS: selectores, texto, colores, box model, display y position, flexbox, transiciones, animaciones y media queries

Selectores

Base + atributo + combinadores + pseudo-clases + pseudo-elementos


/* Básicos */
* { box-sizing: border-box; }
h1 { font-size: 2rem; }
.destacado { font-weight: 700; }
#encabezado { text-align: center; }

/* Atributo */
input[type="text"] { border: 1px solid #ccc; }
a[href*="github"] { color: #333; }
img[src^="https"] { border: 2px solid green; }
a[href$=".pdf"] { color: red; }

/* Combinadores */
article p { line-height: 1.6; }   /* descendiente */
nav > ul { list-style: none; }    /* hijo directo */
h2 + p { margin-top: 0; }         /* adyacente */
h2 ~ p { color: #666; }           /* hermanos */

/* Pseudo-clases */
a:hover { text-decoration: underline; }
input:focus { outline: 2px solid #8fd1fc; }

/* Estructurales */
li:first-child { font-weight: 700; }
tr:nth-child(even) { background: #f9fafb; }

/* Pseudo-elementos */
p::first-line { font-weight: 700; }
::selection { background: #ffda73; color: #282828; }
  • Regla práctica: clase para estilos, id para JS/anclas.
  • Prioriza selectores simples (mejor mantenibilidad).

Propiedades de texto

Fuente + formato + truncado + responsive.


/* Fuente */
body { font-family: 'Arial', sans-serif; }
h1 { font-size: 2rem; }
.subtitulo { font-size: clamp(1.2rem, 2vw, 1.5rem); }

/* Formato */
p { line-height: 1.6; }
.resaltado { color: #e63946; }
.cursiva { font-style: italic; }

/* Truncado */
.truncado {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
    max-width: 200px;
}

Colores

Formatos + background + gradientes + variables CSS.


/* Formatos */
.color { color: #785082; }
.fondo { background: rgb(240, 180, 0); }
.sombra { box-shadow: 0 8px 18px rgba(0,0,0,.12); }

/* Fondo con imagen */
.hero {
    background-image: url("img.jpg");
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

/* Gradiente */
.banner {
    background: linear-gradient(135deg, #785082, #6990aa);
}

/* Variables (ya las tienes en :root) */
.btn {
    color: var(--white);
    background: var(--secondary);
}

Box Model

Width/height + padding + border + margin + box-sizing.


.card {
    width: min(520px, 100%);
    padding: 20px;
    margin: 20px auto;

    border: 1px solid var(--light);
    border-radius: 10px;

    box-shadow: 0 10px 24px rgba(0,0,0,.08);
    overflow: hidden;
}

/* outline (no ocupa espacio) */
    .input:focus {
        outline: 2px solid var(--accent);
        outline-offset: 2px;
}

Display / Position

Valores + posicionamiento + flexbox + grid.


/* Valores comunes */
.block { display: block; }
.inline { display: inline; }
.inline-block { display: inline-block; }
.none { display: none; }

/* Posicionamiento */
.relative { position: relative; }
.absolute { position: absolute; }
.fixed { position: fixed; }

/* Flexbox */
.flex {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
}

/* Grid */
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-gap: 20px;
}

Flexbox

Contenedor flexible para layouts 1D.


.row {
    display: flex;
    align-items: center;
    justify-content: space-between;
    gap: 16px;
}

.wrap {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}

.item {
    flex: 1 1 240px; /* grow shrink basis */
}

.push-right {
    margin-left: auto; /* empuja a la derecha */
}

Transiciones

Animar cambios sin JS (hover, focus, etc.).


.btn {
    transition: background 0.3s ease, color 0.3s ease;
}

.btn:hover {
    background: var(--accent);
    color: var(--white);
}

Animaciones

Animar con keyframes para efectos más complejos (duración, delay, fill-mode).


@keyframes fadeUp {
    from { opacity: 0; transform: translateY(10px); }
    to   { opacity: 1; transform: translateY(0); }
}

.aparece {
    animation: fadeUp .35s ease-out both;
}

/* Accesibilidad */
@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; transition: none !important; }
}

Media Queries

Diseño responsive con breakpoints para adaptar el layout a diferentes tamaños de pantalla.


/* Mobile first: estilos base para móvil, luego media queries para desktop */
.container {
    display: block;
}

/* Tablet */
@media (min-width: 768px) {
    .container { padding: 24px; }
}

/* Desktop */
@media (min-width: 1024px) {
    .container { padding: 32px; }
}

/* Dark scheme (si quieres complementarlo a tu .dark) */
@media (prefers-color-scheme: dark) {
    :root { color-scheme: dark; }
}
